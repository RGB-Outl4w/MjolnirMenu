The mod menu Odin would ban you for.

MjolnirMenu is an in-game trainer for Valheim. Press Insert, get ten tabs of toggles — survival, movement, combat, world, skills, effects, spawner, teleport, ESP — and switch every one of them back off in a single keypress. No console commands, no config editing, nothing left behind on logout.

Install in four steps

Windows, Steam. Takes about two minutes.

  1. Install BepInEx

    Get BepInExPack_Valheim and extract it into your Valheim folder (winhttp.dll lands next to valheim.exe).

  2. Run the game once

    Launch Valheim so BepInEx creates its config and plugins folders, then quit.

  3. Drop in the DLL

    Put MjolnirMenu.dll from the latest release into Valheim\BepInEx\plugins\MjolnirMenu\.

  4. Play

    Start the game, load a world, press Insert. BepInEx\LogOutput.log should say Loading [MjolnirMenu].

Building from source instead 
# needs .NET SDK 8+ and Valheim installed
$env:VALHEIM_DIR = "C:\Program Files (x86)\Steam\steamapps\common\Valheim"
dotnet build src\MjolnirMenu -c Release   # auto-deploys into BepInEx\plugins when present

Game assemblies are referenced from valheim_Data\Managed; BepInEx and HarmonyX come from the BepInEx NuGet feed. Nothing from the game is redistributed.

Hotkeys

All rebindable in BepInEx/config/com.mjolnir.menu.cfg.

InsertOpen / close the menu. While open, the game's input gates report false: keys and clicks go to the menu, not your character.
F6Toggle god mode
F7Toggle fly
EndPanic — every cheat off at once
Ctrl + ClickOn the big map: teleport there (when map teleport is on)

Presets

Save the whole menu state under a name from the Settings tab. Presets are plain Key=Value files in MjolnirMenu.presets/ — safe to share, easy to hand-edit. Mark one Auto-load and it's applied the moment you spawn in.

# MjolnirMenu preset  v0.6.0
GodMode=true
Fly=false
SpeedHack=true
SpeedMultiplier=3
InfiniteItems=true
HideCheatTags=true

FAQ

Does it work in multiplayer?

Client-side effects (movement, ESP, the menu) work anywhere. Damage multipliers are applied before a hit is sent to the target's owner, so they work too. Nothing is hidden from a server or other players — see the fair play notice.

My loot says "obtained using cheats".

That's Valheim's own flag: the game marks you as a cheater the first time you deal damage in god / ghost / fly mode and stamps every drop afterwards. Settings → Cheat tags is on by default and reports the game's own bypass key; Clear tags on items in inventory fixes what you already carry.

A spawned item behaves strangely.

The spawner hides prefabs that aren't real inventory items (monster weapons, effect objects). If you turned on Show all, those are exactly the ones that misbehave.

Will it break my save?

Every cheat is reconciled against the game each frame and restored to vanilla values when toggled off or on logout. Skills and forsaken powers are written through the game's own fields, so they persist exactly as if you'd earned them.

Which game version?

Built and tested against the current Steam build (1.0.x, Deep North). Method signatures were verified against assembly_valheim.dll with Mono.Cecil before each patch was written. A game update that renames a patched method will show up as a Harmony error in LogOutput.log — open an issue with that log.
